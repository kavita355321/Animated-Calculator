# 🔢 Animated Calculator

A fully responsive, animated calculator built with HTML, CSS, and JavaScript. Features include:

- Light & Dark Mode 🌙
- Smooth Animations ✨
- Calculation History 🧾
- Backspace Functionality ⌫
- Mobile Responsive 📱
- Beautiful Gradient Buttons 🎨
